# Game Design Doc — ພະຈົນໄພຄວາມຮູ້ (Village Hub)

Oct 28, 2026 · @Kittisay

## ພາບລວມເກມ

ເກມ side-scroll adventure RPG ສ້າງດ້ວຍ Phaser 3. ຫຼັກການສຳຄັນ: **ຄວາມຮູ້ = ພະລັງ**. ຜູ້ຫຼິ້ນຈະເກັ່ງຂຶ້ນໄດ້ກໍ່ຕໍ່ເມື່ອຮຽນ.

| ຫົວຂໍ້ | ລາຍລະອຽດ |
| --- | --- |
| ຊື່ຊົ່ວຄາວ | ພະຈົນໄພຄວາມຮູ້ (Knowledge Quest) |
| ແນວເກມ | 2D side-scroll, action RPG, crafting |
| ກຸ່ມເປົ້າໝາຍ | ນັກຮຽນວິທະຍາໄລເຕັກນິກ-ວິຊາຊີບ |
| Platform | Web browser (desktop + mobile), Phaser 3 |
| ເວລາຫຼິ້ນ 1 ຮອບ | 15–20 ນາທີ (ອອກສຳຫຼວດ 1 ຄັ້ງ + ກັບໝູ່ບ້ານ) |
| ໂຄງສ້າງ | ແບ່ງເປັນ Chapter; 1 Chapter = 1 ບົດຮຽນ = 1 ເຂດ (region) |

**ເປົ້າໝາຍການຮຽນ:** ນັກຮຽນອ່ານເນື້ອຫາຫຍໍ້ໃນປຶ້ມຕຳລາ ແລະ ຕອບຄຳຖາມຊ້ຳຫຼາຍຄັ້ງຜ່ານການຫຼິ້ນ. ເນື້ອຫາ ແລະ ຄຳຖາມເກັບໃນໄຟລ໌ JSON ເພື່ອໃຫ້ຄູປ່ຽນວິຊາໄດ້ໂດຍບໍ່ແກ້ code.

**ຂໍ້ສົມມຸດ:** "ເຄດ" ໃນເອກະສານນີ້ໝາຍເຖິງ **Credit** — ສະກຸນເງິນທີ່ໄດ້ຈາກການຮຽນເທົ່ານັ້ນ.

## Core Game Loop

ເກມມີ 3 ຊັ້ນ loop ຊ້ອນກັນ: loop ນ້ອຍໃນດ່ານ, loop ກາງລະຫວ່າງໝູ່ບ້ານກັບດ່ານ, ແລະ loop ໃຫຍ່ຕາມ Chapter.

&#91;embedded content: Village Hub loop · 6 ຂັ້ນ, 1 loop ກັບບ້ານ\]

Loop ກາງ (ເສັ້ນດ້ານເທິງ) ວົນ 2–3 ຮອບຕໍ່ Chapter ກ່ອນຜູ້ຫຼິ້ນພ້ອມສ້ອມປະຕູ ແລະ ສູ້ Boss.

- **Loop ນ້ອຍ (ໃນດ່ານ, 30 ວິນາທີ–2 ນາທີ):** ຍ່າງ → ເຫັນຊັບພະຍາກອນ/ສັດຕູ → ເກັບ ຫຼື ສູ້ → ໄດ້ຂອງ drop
- **Loop ກາງ (1 ຮອບອອກສຳຫຼວດ, 15–20 ນາທີ):** ຮຽນ → ສ້າງ → ສຳຫຼວດ → ກັບບ້ານ
- **Loop ໃຫຍ່ (1 Chapter, \~1 ຊົ່ວໂມງ):** ປຶ້ມໃໝ່ → ເຄື່ອງມືໃໝ່ → ເຂດໃໝ່ → Boss → Chapter ຕໍ່ໄປ

## ໝູ່ບ້ານ (Hub)

ໝູ່ບ້ານເປັນ scene ທີ່ປອດໄພ ບໍ່ມີສັດຕູ. ຜູ້ຫຼິ້ນຍ່າງ side-scroll ໄປຫາອາຄານ ແລ້ວກົດ interact ເພື່ອເປີດ UI ຂອງອາຄານນັ້ນ.

| ອາຄານ | ໜ້າທີ່ | ໃຊ້ຫຍັງ | ໄດ້ຫຍັງ |
| --- | --- | --- | --- |
| ຫໍສະໝຸດ (Library) | ຊື້ ແລະ ອ່ານປຶ້ມຕຳລາ | Credit | ປຶ້ມ (ເນື້ອຫາບົດຮຽນ) |
| ຫ້ອງຮຽນ (Academy) | ສອບປຶ້ມ, ຝຶກຄຳຖາມປະຈຳວັນ | ຄວາມຮູ້ | Credit, ປົດລັອກ recipe |
| ໂຮງຊ່າງ (Workshop) | ສ້າງເຄື່ອງມື ແລະ Repair Kit | ວັດສະດຸ + recipe | ຂວານ, ຈົກ, ຄ້ອນ, Repair Kit |
| ໂຮງຕີເຫຼັກ (Forge) | ສ້າງ ແລະ ອັບເກຣດອາວຸດ/ເກາະ | ວັດສະດຸ + Credit + recipe | ອາວຸດ Tier ສູງຂຶ້ນ |
| ກະດານພາລະກິດ (Quest Board) | ຮັບ quest ຍ່ອຍ | — | Credit, ວັດສະດຸພິເສດ |
| ຄັງເກັບ (Storage) | ເກັບຂອງເກີນກະເປົາ | — | — |
| ປະຕູໝູ່ບ້ານ (World Gate) | ເລືອກດ່ານອອກສຳຫຼວດ | — | ເຂົ້າ Stage |

**ກົດຂອງໝູ່ບ້ານ:**

- ກັບໝູ່ບ້ານແລ້ວ HP ເຕັມອັດຕະໂນມັດ ແລະ save ເກມ
- ອາຄານໃໝ່ປົດລັອກຕາມ Chapter (ເຊັ່ນ Forge ເປີດຫຼັງຊະນະ Boss ທຳອິດ) ເພື່ອບໍ່ໃຫ້ນັກຮຽນສັບສົນຕອນເລີ່ມ
- NPC ໃນແຕ່ລະອາຄານໃຫ້ hint ສັ້ນໆ ວ່າຄວນເຮັດຫຍັງຕໍ່

## ດ່ານສຳຫຼວດ (Stage)

1 Chapter ມີ 1 Stage ແບ່ງເປັນ 4 ເຂດ ຍ່າງຈາກຊ້າຍໄປຂວາ. ຜູ້ຫຼິ້ນອອກມາ ແລະ ກັບບ້ານໄດ້ຫຼາຍຄັ້ງ; ດ່ານຈະ respawn ຊັບພະຍາກອນ ແລະ ສັດຕູທຸກຄັ້ງທີ່ເຂົ້າໃໝ່.

1. **ເຂດ A — ປ່າຊາຍແດນ:** ຊັບພະຍາກອນພື້ນຖານ, ສັດຕູອ່ອນ. ເໝາະກັບການເກັບຂອງ
2. **ເຂດ B — ຖໍ້າ / ເນີນຫີນ:** ຕ້ອງມີຈົກ (Pickaxe) ຈຶ່ງຂຸດແຮ່ໄດ້, ສັດຕູແຂງຂຶ້ນ, ທ້າຍເຂດມີ **Mini-boss**
3. **ປະຕູພັງ (Broken Gate):** ກັ້ນທາງໄປເຂດ C. ສ້ອມແປງດ້ວຍ Repair Kit + ຕອບຄຳຖາມ 1 ຂໍ້ (ຖ້າຜິດ Kit ບໍ່ເສຍ, ຕອບໃໝ່ໄດ້ຂໍ້ອື່ນ)
4. **ເຂດ C — ລານ Boss:** ສູ້ **Boss ປະຈຳດ່ານ**. ຊະນະແລ້ວປົດລັອກ Chapter ຕໍ່ໄປ

**ຊັບພະຍາກອນ (Chapter 1):**

| ຊັບພະຍາກອນ | ພົບທີ່ | ເຄື່ອງມືທີ່ຕ້ອງໃຊ້ |
| --- | --- | --- |
| ໄມ້ (Wood) | ເຂດ A | ຂວານ |
| ຫີນ (Stone) | ເຂດ A, B | ຈົກ Tier 1 |
| ແຮ່ເຫຼັກ (Iron Ore) | ເຂດ B | ຈົກ Tier 1 |
| ສະໝຸນໄພ (Herb) | ເຂດ A | ມືເປົ່າ |
| ຜລຶກ (Crystal) | Mini-boss drop | — |
| ແກນ Boss (Boss Core) | Boss drop | — |

**ສັດຕູ ແລະ ການ drop:**

| ປະເພດ | ລັກສະນະ | Drop |
| --- | --- | --- |
| ສັດຕູທຳມະດາ | ຍ່າງໄປມາ, ໂຈມຕີໃກ້ | ໜັງ, ເສັ້ນໃຍ, ສະໝຸນໄພ |
| ສັດຕູ Elite | HP ສູງ, ມີທ່າພິເສດ 1 ທ່າ | ວັດສະດຸຫາຍາກ |
| Mini-boss | 2 ທ່າໂຈມຕີ, ກັນເຂດ B | ຜລຶກ (ໃຊ້ສ້າງ Repair Kit) |
| Boss | 2–3 phase, ປ່ຽນທ່າເມື່ອ HP ຫຼຸດ | Boss Core + ປຶ້ມ Chapter ຕໍ່ໄປ |

**ການອອກແບບສຳຄັນ:** Mini-boss drop ຜລຶກທີ່ໃຊ້ສ້າງ Repair Kit. ດັ່ງນັ້ນລຳດັບແມ່ນ ຊະນະ Mini-boss → ກັບບ້ານສ້າງ Kit → ກັບມາສ້ອມປະຕູ. ນີ້ບັງຄັບໃຫ້ loop ກັບໝູ່ບ້ານເກີດຂຶ້ນຢ່າງເປັນທຳມະຊາດ.

## ລະບົບການຮຽນ

ການຮຽນມີ 3 ຊ່ອງທາງ: ອ່ານປຶ້ມ → ສອບປຶ້ມ → ຝຶກຊ້ຳ. ທຸກຊ່ອງທາງໃຫ້ Credit ຫຼື ປົດລັອກຂອງ.

**1. ປຶ້ມຕຳລາ (Textbook)**

- ຊື້ທີ່ຫໍສະໝຸດດ້ວຍ Credit. ປຶ້ມທຳອິດຂອງແຕ່ລະ Chapter ໄດ້ຟຣີ
- 1 ປຶ້ມ = 3–5 ໜ້າສັ້ນ (ແຕ່ລະໜ້າ 1 ແນວຄິດ, ຂໍ້ຄວາມ + ຮູບ). ເນັ້ນເນື້ອຫາ Must-know
- ອ່ານຊ້ຳໄດ້ຕະຫຼອດຈາກ inventory (ໃຊ້ທົບທວນກ່ອນສອບ)

**2. ສອບປຶ້ມ (Book Exam) ທີ່ຫ້ອງຮຽນ**

- 5 ຄຳຖາມສຸ່ມຈາກ question bank ຂອງປຶ້ມນັ້ນ; ຖືກ 4/5 = ຜ່ານ
- ຜ່ານ → ໄດ້ Credit + **ປົດລັອກ recipe** ທີ່ຜູກກັບປຶ້ມ (ເຊັ່ນ ປຶ້ມ "ໂລຫະ" ປົດລັອກ ດາບເຫຼັກ)
- ບໍ່ຜ່ານ → ສະແດງຄຳອະທິບາຍ + ບອກໜ້າໃນປຶ້ມທີ່ມີຄຳຕອບ; ສອບໃໝ່ໄດ້ທັນທີ ແຕ່ຄຳຖາມຈະສຸ່ມໃໝ່

**3. ຝຶກປະຈຳວັນ (Daily Practice)**

- ຄຳຖາມ 3 ຂໍ້/ວັນ ຈາກປຶ້ມທີ່ອ່ານແລ້ວ ໃຫ້ Credit ເລັກນ້ອຍ
- ຄຳຖາມທີ່ເຄີຍຕອບຜິດຈະອອກຊ້ຳຫຼາຍກວ່າ (spaced repetition ແບບງ່າຍ)

**4. ຄຳຖາມໃນສະໜາມ:** ປະຕູພັງ ແລະ Boss phase ສຸດທ້າຍ ຖາມ 1 ຂໍ້ ເພື່ອໃຫ້ຄວາມຮູ້ຢູ່ໃນ action ນຳ.

**ປະເພດຄຳຖາມ:** ເລືອກຕອບ (multiple choice), ຖືກ/ຜິດ, ຈັດລຳດັບ, ຈັບຄູ່. ເລີ່ມ MVP ດ້ວຍ multiple choice ຢ່າງດຽວ.

**ກົດສຳຄັນ:** ຕອບຜິດບໍ່ລົງໂທດໜັກ (ບໍ່ເສຍ Credit, ບໍ່ເສຍຂອງ). ພຽງແຕ່ບໍ່ໄດ້ລາງວັນ ແລະ ໄດ້ຄຳອະທິບາຍແທນ, ເພື່ອໃຫ້ນັກຮຽນກ້າລອງ.

## Crafting ແລະ Upgrade

ທຸກ recipe ຕ້ອງປົດລັອກດ້ວຍການສອບປຶ້ມກ່ອນ. ສູດ: **Recipe (ຄວາມຮູ້) + ວັດສະດຸ (ສຳຫຼວດ) + Credit (ຮຽນ) = ຂອງໃໝ່**.

**ເຄື່ອງມື (Tools) — ສ້າງທີ່ Workshop:**

| ເຄື່ອງມື | ໃຊ້ເຮັດຫຍັງ | ວັດສະດຸ (ຕົວຢ່າງ) |
| --- | --- | --- |
| ຂວານ T1 | ຕັດໄມ້ | ໄມ້ 3, ຫີນ 2 |
| ຈົກ T1 | ຂຸດຫີນ, ແຮ່ເຫຼັກ | ໄມ້ 2, ຫີນ 4 |
| ຄ້ອນຊ່າງ | ຈຳເປັນຕອນສ້ອມປະຕູ | ໄມ້ 2, ແຮ່ເຫຼັກ 2 |
| Repair Kit | ສ້ອມປະຕູພັງ (ໃຊ້ແລ້ວໝົດ) | ໄມ້ 5, ແຮ່ເຫຼັກ 3, ຜລຶກ 1 |

**ອາວຸດ (Weapons) — ສ້າງ ແລະ ອັບເກຣດທີ່ Forge:**

| Tier | ຕົວຢ່າງ | ຕ້ອງການ | ຜົນ |
| --- | --- | --- | --- |
| T1 | ດາບໄມ້ | ເລີ່ມເກມໄດ້ເລີຍ | ຄວາມແຮງພື້ນຖານ |
| T2 | ດາບເຫຼັກ | recipe ປຶ້ມ Ch.1 + ແຮ່ເຫຼັກ + Credit | ພຽງພໍສູ້ Boss Ch.1 |
| T3 | ດາບຜລຶກ | recipe ປຶ້ມ Ch.2 + Boss Core + Credit | ສູ້ Chapter 2 |

**ລະດັບ upgrade ພາຍໃນ Tier:** ແຕ່ລະອາວຸດ upgrade ໄດ້ +1 ຫາ +3 ໂດຍໃຊ້ວັດສະດຸ + Credit. ເມື່ອ +3 ແລ້ວຕ້ອງໄປ Tier ຕໍ່ໄປ (ຕ້ອງອ່ານປຶ້ມໃໝ່).

**ອຸປະກອນເສີມ (ທາງເລືອກ):** ເກາະ (ເພີ່ມ HP), ຢາຟື້ນ HP ຈາກສະໝຸນໄພ. ສາມາດເພີ່ມໃນ phase ຫຼັງ MVP.

## ເສດຖະກິດເກມ ແລະ Balance

ມີ 2 ຊັບສິນແຍກກັນ: **ວັດສະດຸ** ໄດ້ຈາກການສຳຫຼວດເທົ່ານັ້ນ, **Credit** ໄດ້ຈາກການຮຽນເທົ່ານັ້ນ. ຂ້າສັດຕູບໍ່ໄດ້ Credit — ເພື່ອບໍ່ໃຫ້ນັກຮຽນ farm ສັດຕູແທນການຮຽນ.

**ແຫຼ່ງ Credit ແລະ ຈຸດໃຊ້ Credit (ຕົວເລກເລີ່ມຕົ້ນ, ປັບຫຼັງ playtest):**

| ທີ່ມາ / ທີ່ໃຊ້ | Credit |
| --- | --- |
| ສອບປຶ້ມຜ່ານ (ຄັ້ງທຳອິດ) | +50 |
| ສອບປຶ້ມຊ້ຳ (ຫຼັງຜ່ານແລ້ວ) | +5 |
| ຝຶກປະຈຳວັນ (ຕໍ່ຂໍ້ທີ່ຖືກ) | +5 |
| Quest ຍ່ອຍ | +10 ຫາ +20 |
| ຊື້ປຶ້ມ | −30 ຫາ −60 |
| ສ້າງອາວຸດ T2 | −40 |
| Upgrade +1 / +2 / +3 | −10 / −20 / −30 |

**ຫຼັກ Balance:**

- ຄວາມແຮງຂອງ Boss ຕັ້ງໃຫ້ຊະນະໄດ້ງ່າຍດ້ວຍ T2 ແຕ່ຍາກຫຼາຍດ້ວຍ T1 → ຜູ້ຫຼິ້ນຕ້ອງຮຽນກ່ອນສູ້
- ກະເປົາມີຂີດຈຳກັດ (ເຊັ່ນ 20 ຊ່ອງ) → ບັງຄັບໃຫ້ກັບບ້ານເປັນໄລຍະ
- ຕາຍໃນດ່ານ → ກັບບ້ານ, ເສຍວັດສະດຸທີ່ຖືຢູ່ 50% (ບໍ່ເສຍ Credit ແລະ ເຄື່ອງມື)
- 1 Chapter ຄວນໃຊ້ເວລາ 3–4 ຮອບອອກສຳຫຼວດ (ປະມານ 1 ຊົ່ວໂມງ) — ພໍດີກັບ 1 ຄາບຮຽນ ຫຼື ການບ້ານ

## ຕົວຢ່າງການຫຼິ້ນ Chapter 1

Chapter 1 ຈົບໃນ 4 ຮອບອອກສຳຫຼວດ:

1. **ເລີ່ມເກມ:** ຢູ່ໝູ່ບ້ານ ມີດາບໄມ້ + ຂວານ T1. ໄດ້ປຶ້ມ Ch.1 ຟຣີ → ອ່ານ 3 ໜ້າ → ສອບທີ່ Academy ຜ່ານ → +50 Credit, ປົດລັອກ recipe ຈົກ T1 ແລະ ດາບເຫຼັກ
2. **ຮອບ 1:** ອອກໄປເຂດ A ຕັດໄມ້, ເກັບຫີນ ແລະ ສະໝຸນໄພ, ຂ້າສັດຕູອ່ອນ → ກະເປົາເຕັມ ກັບບ້ານ → ສ້າງຈົກ T1
3. **ຮອບ 2:** ເຂົ້າເຂດ B ຂຸດແຮ່ເຫຼັກ, ພົບ Mini-boss ແລະ ຊະນະ → ໄດ້ຜລຶກ → ກັບບ້ານສ້າງ Repair Kit + ຄ້ອນ, ສ້າງດາບເຫຼັກ T2
4. **ຮອບ 3:** ໄປປະຕູພັງ ໃຊ້ Kit + ຕອບຄຳຖາມ → ປະຕູເປີດ → ລອງສູ້ Boss ແຕ່ແພ້ → ກັບບ້ານ ຝຶກປະຈຳວັນເອົາ Credit → upgrade ດາບເຫຼັກ +2
5. **ຮອບ 4:** ເຂົ້າລານ Boss ໂດຍກົງ (ປະຕູເປີດຄ້າງໄວ້) → Boss phase ສຸດທ້າຍຖາມ 1 ຂໍ້ → ຊະນະ → ໄດ້ Boss Core + ປຶ້ມ Ch.2 → Forge ອັບເກຣດ, ເຂດ Chapter 2 ເປີດ

ສັງເກດ: ທຸກຄັ້ງທີ່ຕິດ (ຂຸດແຮ່ບໍ່ໄດ້, ປະຕູພັງ, Boss ແຂງ) ທາງອອກແມ່ນ **ກັບໄປຮຽນ ແລະ ສ້າງ** — ນີ້ແມ່ນຫົວໃຈຂອງ Village Hub loop.

## ໂຄງສ້າງ Phaser

ແຍກ code (logic) ອອກຈາກ data (ເນື້ອຫາ). ຄູແກ້ພຽງໄຟລ໌ JSON ກໍ່ປ່ຽນວິຊາໄດ້.

**Scenes:**

| Scene | ໜ້າທີ່ |
| --- | --- |
| BootScene / PreloadScene | ໂຫຼດ asset ແລະ JSON ທັງໝົດ |
| TitleScene | ໜ້າເລີ່ມ, ເລືອກ save slot |
| HubScene | ໝູ່ບ້ານ, ຍ່າງໄປຫາອາຄານ |
| StageScene | ດ່ານ side-scroll (ໂຫຼດ layout ຕາມ stages.json) |
| UIScene | HUD ຊ້ອນທັບ: HP, Credit, ກະເປົາ (run ຂະໜານກັບ Hub/Stage) |
| QuizScene | overlay ຄຳຖາມ, pause scene ດ້ານລຸ່ມ ແລ້ວສົ່ງຜົນກັບ |
| BuildingScene | UI ຂອງອາຄານ (Library, Workshop, Forge...) ໃຊ້ scene ດຽວ ປ່ຽນຕາມ type |

**ໄຟລ໌ data (ໃນ `public/data/`):**

- `books.json` — ປຶ້ມ: id, chapter, ລາຄາ, ໜ້າເນື້ອຫາ, recipe ທີ່ປົດລັອກ
- `questions.json` — id, bookId, ຄຳຖາມ, choices, ຄຳຕອບ, ຄຳອະທິບາຍ, ໜ້າອ້າງອີງ
- `items.json` — ວັດສະດຸ, ເຄື່ອງມື, ອາວຸດ ພ້ອມ stat
- `recipes.json` — ວັດສະດຸທີ່ຕ້ອງໃຊ້, Credit, ຕ້ອງການປຶ້ມໃດ
- `stages.json` — ເຂດ, ຈຸດເກີດຊັບພະຍາກອນ, ສັດຕູ, mini-boss, boss
- `enemies.json` — HP, damage, ທ່າໂຈມຕີ, drop table

**ຕົວຢ່າງ 1 ຄຳຖາມ:**

```json
{
  "id": "q-ch1-001",
  "bookId": "book-ch1",
  "question": "ຂໍ້ໃດແມ່ນອຸປະກອນ input?",
  "choices": ["Monitor", "Keyboard", "Printer", "Speaker"],
  "answer": 1,
  "explain": "Keyboard ໃຊ້ປ້ອນຂໍ້ມູນເຂົ້າຄອມພິວເຕີ",
  "page": 2
}
```

**Game state ແລະ Save:**

- ເກັບ state ສ່ວນກາງໃນ `GameState` class (ຫຼື Phaser registry): Credit, inventory, ເຄື່ອງມື, ປຶ້ມທີ່ມີ, recipe ທີ່ປົດລັອກ, chapter, ປະຕູທີ່ເປີດແລ້ວ, ສະຖິຕິຄຳຖາມ
- MVP: save ລົງ `localStorage` ເມື່ອກັບໝູ່ບ້ານ
- ຂັ້ນຕໍ່ໄປ: ສົ່ງຜົນຄຳຖາມໄປ Laravel API ເພື່ອໃຫ້ຄູເບິ່ງ dashboard ຄວາມຄືບໜ້າຂອງນັກຮຽນໃນ Filament

## ຂອບເຂດ MVP ແລະ ລຳດັບການພັດທະນາ

MVP = Chapter 1 ຫຼິ້ນໄດ້ຄົບ loop ຕັ້ງແຕ່ຕົ້ນຈົນຊະນະ Boss. ສິ່ງອື່ນເກັບໄວ້ phase ຕໍ່ໄປ.

**ໃນ MVP:** ໝູ່ບ້ານ 4 ອາຄານ (Library, Academy, Workshop, Forge), 1 Stage 4 ເຂດ, ຊັບພະຍາກອນ 4 ຢ່າງ, ສັດຕູ 2 ແບບ, Mini-boss 1, Boss 1, ປຶ້ມ 1 ຫົວ + ຄຳຖາມ 15–20 ຂໍ້ (multiple choice), recipe 5 ຢ່າງ, save ດ້ວຍ localStorage.

**ນອກ MVP:** Quest Board, Storage, ອຸປະກອນເສີມ, ຄຳຖາມແບບຈັບຄູ່/ຈັດລຳດັບ, Laravel API + dashboard ຄູ.

- [ ] 1\. ຕັ້ງ project Vite + Phaser 3 + TypeScript, ສ້າງ BootScene/PreloadScene ແລະ ໄຟລ໌ JSON ຕົວຢ່າງ
- [ ] 2\. StageScene: ຕົວລະຄອນຍ່າງ, ໂດດ, ໂຈມຕີ, ກ້ອງຕາມ (ໃຊ້ຮູບສີ່ຫຼ່ຽມແທນ sprite ກ່ອນ)
- [ ] 3\. ເກັບຊັບພະຍາກອນ + inventory + UIScene (HUD)
